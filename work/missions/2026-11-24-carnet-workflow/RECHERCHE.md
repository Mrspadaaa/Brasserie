# Voie recherche — état de l'art : suivre un problème jusqu'à sa résolution, de façon simple, visuelle et un peu ludique

- Agent : general-purpose ; Modèle : sonnet ; Niveau : jugement (recherche) ; Plafond : 60 tours.
- Lis SES-MOTS.md (même dossier) en entier, puis PRODUCT.md (parties Carnet, Matériel, Brassins) seulement.
- Rends ETAT-DE-L-ART.md (même dossier, 1 500 mots au plus) :
  1. Le problème d'école : nommer les familles (suivi d'incidents / tickets, GMAO pour petits ateliers, journal de bord, listes de tâches, liste d'achats avec veille de stock, base de connaissances « pourquoi j'ai choisi ça »).
  2. 8 à 12 outils ou motifs réels examinés (ex. Things, Todoist, Linear, GitHub Issues, Trello, Notion, Apple Notes, MaintainX/UpKeep pour la maintenance, Keepa/camelcamelcamel pour les alertes de prix et de stock, Habitica/Duolingo pour le ludique), chacun : ce qui le rend facile, visuel, fun ; ce qui le rend lourd ; ce qu'on en reprendrait.
  3. Les cycles de vie (problème → recherche → options → choix → achat → résolu → retrouvable) et les états minimaux.
  4. 10 à 15 usages réels d'une micro-brasserie (les siens + d'autres trouvés : vapeur, fusible, fuite, débit de transfert, moisissure, fenêtre, …).
  5. Ce qui rend un outil utilisé au quotidien par quelqu'un qui « ne note rien » (friction de saisie, voix et photo, rappels, récompense, vue d'ensemble).
  6. 5 recommandations pour le Carnet de L'Affinée (s'appuyer sur l'existant : notes, IA de rangement, articles, Comparer, Calendrier, À venir, « trigger » de stock).
- Recherche web autorisée (lecture seule, aucun compte, aucun formulaire). Aucun fichier de src/ modifié. Ligne de fin : « RECHERCHE OK <n outils> ».
