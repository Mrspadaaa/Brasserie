# f3e — « Le ruban du mois »
**Idée** : les piles couchées en deux rubans à même échelle, Ventes au-dessus, dépenses dessous ; la pièce s'insère, lumineuse, et pousse la suite. Fermé, le ruban lui-même est l'onglet.
**Axes** : 1 ruban fin toujours visible au-dessus d'Enregistrer, qui s'étire en feuille ; 2 segment lumineux inséré + pastille ; 3 piles seules ; 4 payée ; 5 le ruban Ventes s'allonge (+54,00).
**Chaleur** : chaude. Boosters : `ruban-onglet`, `rubans`.
**Contrôles** : PAGE OK ; PANEL OK ; cibles ≥ 24 px (bande 34 px) ; rien sous 11 px.
**Ce qui casse** : Nettoyage et Matériel trop fins pour un nom dans le ruban (légende à part) ; un vide de 40 px sous le titre.
