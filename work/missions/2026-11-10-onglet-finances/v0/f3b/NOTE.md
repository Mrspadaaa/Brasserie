# f3b — « Le mois en anneaux »
**Idée** : les piles pliées en anneaux concentriques (Ventes dehors, Matériel dedans, même échelle) ; la pièce allonge son anneau d'un arc lumineux, un trait noir marque l'avant, l'écart au centre.
**Axes** : 1 bouton-anneau dans le pied, à gauche d'Enregistrer ; 2 arc lumineux + trait « avant » + écart central ; 3 piles seules ; 4 payée ; 5 l'anneau Ventes s'allonge (+54,00).
**Chaleur** : chaude. Boosters : `anneau-pied`, `anneaux-mois`.
**Contrôles** : PAGE OK ; PANEL OK ; cibles ≥ 24 px ; rien sous 11 px ; 270° = 774,00 pour tous les anneaux.
**Ce qui casse** : un arc se compare moins vite qu'une hauteur ; le quart bas-gauche est vide ; en caisse, le bouton raccourcit « Encaisser ».
