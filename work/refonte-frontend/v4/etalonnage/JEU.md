## Limites connues

- Une même préférence nourrit plusieurs paires (r6a contre quatre autres, y1b contre quatre, f1 contre cinq) : à pondérer par préférence dans un score.
- Quand il a dit « A est le meilleur » sur la planche d'un lot, chaque B est une variante du même lot qu'il n'a pas citée : ce n'est pas une phrase « A mieux que B » mot pour mot. Aucune préférence n'est tirée d'un silence ni d'un avis d'agent.
- Paires de picto : f1 contre a1, b1, c1, d1, e1 (un élément de chaque autre série). Il a choisi sur la planche des 48 ; la capture est la planche de la série, pas la planche réunie.
- Lot 4 : le verdict visait la page publiée du 18.10 ; les captures sont celles de la base v3 consolidée (`base/_v3`), la variante exacte vue n'est pas archivée.
- Une part de ses mots porte sur un élément (barres de l5b, rail de p02) ; la capture est l'écran entier.
- Le lot 20 (d1) est cité dans son retour sur le lot 21 ; l5f est du lot 18 jugé le 20.10.
