# cma3 — Lui seul, une rangée

**Chaleur : tiède** (la forme de l'approche ; « hors 16D là où ils comptent »).

## L'idée
« Les type spéciaux des houblons hors 16d ! C'est très important surtout dans la comparaison !!!! » : ce que chaque houblon dit seul devient une rangée du tableau, sous les têtes, alignée comme une famille. ◇ pour un mot hors des 12 familles (violet), le picto de sa famille pour le mot précis (D131 ter). Au repos : deux mots pour le houblon retenu, un pour les autres, « +n » ; un toucher sur la rangée les ouvre tous. La section « ses mots » (« ce texte là est inutile ») disparaît : son contenu est dans la rangée.
Le moment : un fil du temps (un point par moment, le dry hop en bleu acier, à froid) ; les autres lignes en retrait, la choisie en gras.

## Écart déclaré
Le radar r2 passe sous le tableau (un défilement) : « À revoir, on va en parler », « très compliqué à voir les différence avec les cileur sur le spider graph ». Au premier écran : têtes, lui seul, étapes, les neuf familles. Biotransformation et Enchaîner suivent le radar.

## Greffes (data-greffe)

- `cma3-etapes-a-toucher`, `rpb1-wp-actif-apres` : le fil des moments.
