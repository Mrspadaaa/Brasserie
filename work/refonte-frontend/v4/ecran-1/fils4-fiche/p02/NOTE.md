1. **Parti (tiède)** : aperçu « peek » façon menu contextuel iOS : l'écran se floute et s'assombrit, la ligne appuyée est soulevée (net), la carte du houblon se pose au-dessus, les actions dessous (Aimer, Exclure, Ajouter à 10′, Comparer) ; la pile glisse pour tenir dans l'écran, comme iOS.
2. **Geste** : appui long ≈ 500 ms sur tout nom (le pointillé se remplit, vibration brève, la ligne se tasse) ; survol 700 ms à la souris ; toucher à côté, × ou Échap ferment ; toucher la carte ouvre la fiche entière ; une action du menu agit puis ferme ; un toucher court garde son action.
3. **Premier plan (≈ 52 mots dans la fiche, dont la ligne soulevée et le menu)** : nom, origine, exception de stock ; **α 11–14 %** en grand, réglette des sources, « lot 13 % », rôle (« double usage ») ; usage dans cette recette (60′ · 46 g · 60 IBU) ; silhouette en roue 12 axes avec « N/M » ; menu goût et actions.
4. **Replié (fiche entière, au toucher de la carte)** : goût aimer / neutre / exclure, dans ma recette (IBU par gramme selon le moment, stock, styles, substituts « non renseigné »), arômes (descripteurs, autres fiches, auteurs), valeurs (rôle et règle, α β huiles par source), huiles.
5. **Limites** : sous le flou, les textes de l'étape sont masqués (formes gardées) ; « Neutre » n'est pas une entrée du menu : on retouche « Aimé » ou « Exclu » pour revenir ; sur un nom dessiné en SVG (matrice des voies), pas de ligne soulevée, la carte se pose près du nom.
