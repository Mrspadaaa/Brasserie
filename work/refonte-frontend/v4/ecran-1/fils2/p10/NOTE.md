1. **Parti : « La frise et le miroir ».** La recette est posée sur la frise d'ébullition (couloirs 60′, 10′, 0′, DH) : chaque houblon est un bloc dans le couloir de son moment, et les ajouts rapides du stock attendent dans le couloir 10′. La lecture est un papillon : ma bière à gauche, l'après à droite (visée, ajout ou voie), le nom au milieu ; une asymétrie se lit comme un changement.
2. **Recette (récits 1, 2).** H2 + L5 moment qui tourne (le bloc change de couloir, IBU qui roule avec delta, jauge en accent hors bande) ; J3 dose pas à pas ; ajout rapide (un toucher = un bloc à 10′, son effet en fantôme sur l'aile droite quand le moteur le connaît, J6) ; L4 + X6 jauge IBU empilée par houblon (qui apporte l'amertume) dans la bande 50–70 ; L6 compteur qui ouvre le panneau.
3. **Panneau (récits 1, 2, 4, 5).** C1 lentille Barres ↔ Radar : les deux ailes se replient sur le même axe (ma bière et une seule seconde silhouette, C2), radar zoomé au style ; H3 puces de direction ; J1 + J2 cible glissée sur l'aile droite, aimantée aux crans (toucher et flèches en alternative) ; H6 + C6 + X1 focus par le nom central ; L6 + L2 compteurs de groupe, exception seule en accent ; H5 verrou sur les cartes du stock ; C7 tiroir à pages (points-boutons, balayer).
4. **État B (récit 3).** L6 compteurs de voies (floral, ou résine faible avec les pistes hors houblon, A5) ; J6 + C3 fantôme : toucher une carte de voie dessine l'après sur l'aile droite (haltères) et fait rouler l'IBU ; C5 panier, « Comparer (2) » à partir de deux ; L3 mini-profils d'effet sur chaque carte.
5. **Replié.** Chiffres d'une famille (focus), pourquoi « trop » (toucher l'exception), voies au-delà de trois (pages du tiroir ; six cartes en radar), pistes hors houblon (compteur résine), choix de la bière et mention BJCP (pastille 16D), comparaison détaillée (Comparer), catalogue complet (« Ajouter — houblon… »).
